# PDF 签名助手（手机网页 App 原型）

## 使用
1. 将本项目部署到支持 HTTPS 的静态网页托管，或用本地开发服务器测试。
2. iPhone Safari 打开网址，点分享 → 添加到主屏幕。
3. 首次加载需要网络下载 PDF 引擎；缓存后可尝试离线打开。
4. 选择 PDF，绘制或导入签名，点「使用此签名」，再点击 PDF 页面放置。
5. 导出后下载签名 PDF。

## 重要限制
- 本版本是原型，尚未充分测试各种 PDF/移动浏览器兼容性。
- 通过 CDN 加载 PDF.js 和 pdf-lib；首次需要联网，缓存行为受浏览器影响。
- 签名是图像嵌入，不是具有证书验证能力的数字签名。
- 不建议用于法律/合规要求明确的证书签名流程。
- 部署必须使用 HTTPS 才能可靠安装为 PWA。
