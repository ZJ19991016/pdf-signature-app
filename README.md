# PDF 签名助手（微信分享优化版）

## 使用
1. 在 HTTPS 静态托管网站打开；iPhone Safari 可添加到主屏幕。
2. 微信收到 PDF：优先在文件菜单使用“用其他应用打开”；若没有，保存到 iPhone「文件」后，在签名助手点“选择 PDF”。
3. 绘制/导入签名，点击“使用此签名”，再在 PDF 页面放置，可拖动调整。
4. 导出时可点“下载签名 PDF”或“分享回微信”。在支持 Web Share API 文件分享的 iOS 浏览器中会打开系统分享菜单，可选微信；否则下载文件后在微信聊天中发送。

## 限制
- iOS/微信网页环境通常不能保证从微信聊天中的 PDF 一键直接传入网页；网页分享接收能力并非 iPhone Safari/微信通用支持。
- 首次加载 PDF.js 和 pdf-lib 需要网络。
- 签名为图片嵌入，不是带证书的数字签名。
- 不建议用于需要合规证书签名的流程。
